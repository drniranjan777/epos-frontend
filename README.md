# Frontend — Web App

React 19 + Vite + Tailwind CSS 4, React Router, TanStack Query, React Hook Form + Zod, Recharts.
Mobile-first: phones get a bottom navigation bar, drawer, bottom sheets and card lists; desktops get a sidebar and tables.

## Setup

```bash
cd frontend
npm install
cp .env.example .env
npm run dev            # http://localhost:5173 (proxies /api and /uploads to the backend)
```

The backend must be running: https://github.com/drniranjan777/espos-backend

## Scripts

| Script                    | Purpose                                         |
| ------------------------- | ----------------------------------------------- |
| `npm run dev`             | Development server with hot reload              |
| `npm run build`           | Production build into `dist/`                   |
| `npm run preview`         | Serve the production build locally              |
| `npm test`                | Unit/component tests (Vitest + Testing Library) |
| `npm run lint` / `format` | ESLint / Prettier                               |

```
│   ├── inventory/   ProductStockCard, StockMovementSheet, AdjustmentSheet, LedgerList

│   ├── dashboard/   StatCard, MovementChart
│   └── layout/      NavList, UserMenu
├── layouts/         AppLayout → MobileLayout | AdminLayout
├── pages/           one folder per module
├── services/        axios API client + one service per module
├── hooks/           TanStack Query hooks per module, useAuth, useUrlFilters, …
├── context/         AuthProvider
├── routes/          router, auth and permission guards
├── constants/       permissions, navigation, query keys
└── utils/           formatting, GST preview maths, form helpers
```

## Notes

- **Auth**: the access token is kept in memory only; the refresh token is an httpOnly cookie. A reload restores the session through `/auth/refresh`; parallel 401s share a single refresh request.
- **Permissions**: navigation and actions are filtered with `can()` / `canAny()`. The API enforces the same permissions, so hiding a button is only a convenience.
- **Invoice preview** totals are computed in the browser with the same rounding as the server, but the server's figures are what gets saved and printed.
- **Printing**: the invoice page prints only the invoice (`.print-area`) on A4, from phone or desktop. **PDF** is generated by the API.
- List filters live in the URL, so reloads and the back button keep them.
